# Изучение английского с использованием мнемотехники

Обучающее приложение для детей (5–12 лет), помогающее запоминать английские слова с помощью визуальных образов и ассоциаций. Разработано на Python с использованием Tkinter и Pillow. Работает на ОС Windows.

## 🎯 Функциональность

- 5 тематических категорий: «Цвета», «Живые существа», «Съедобное», «Части тела», «Разное».
- Для каждого слова показывается мнемотехническая картинка.
- Воспроизведение правильного произношения (WAV-файлы).
- Проверка знаний: ввод перевода с генерацией случайных слов.
- Результаты тестирования сохраняются в текстовый файл.

## 🚀 Как запустить

1. Убедитесь, что установлен Python 3.6+**.
2. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/eveleinn/python-english-learning-app.git
   cd python-english-learning-app\proekt
   ```
3. Установите библиотеку Pillow
   * Для Python 3.7 и новее:
     ```bash
     pip install Pillow
     ```
   * Для старого Python 3.6:
     ```bash
     pip install "Pillow<=8.4.0"
     ```
4. Перейдите в папку с кодом и запустите приложение:
   ```bash
   cd proekt
   python proekt.py
    ```
